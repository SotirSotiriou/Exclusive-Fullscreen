## Installation
1. Install Spicetify ([Installation Guide](https://spicetify.app/docs/getting-started)).
2. Drop the ``exclusive-fullscreen.js`` file from the repository into the ``%appdata%\spicetify\Extensions`` folder (the extensions folder of Spicetify).
3. Run ``spicetify config extensions exclusive-fullscreen.js`` to enable the extension and then ``spicetify apply`` to apply the changes.
4. There should be a new button visible at the bottom right corner, besides the lyrics button. To go into fullscreen click the it or press ``Ctrl+Shift+F``.
<img width="500" height="100" alt="Exclusive Fullscreen Button" src="https://github.com/user-attachments/assets/63cdc531-0b37-4117-9076-0b7924ae20ac" />

## Update
1. Replace the old script with the new one.
2. Run ``spicetify apply`` to apply the changes.

## Usage
- Use ``Ctrl+Shift+F`` to toggle into fullscreen.
- Use the up and down arrow keys to change the volume.

## Features
- A song's canvas can be used as the background.
- Smooth lyrics with blur
